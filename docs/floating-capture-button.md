# Botón flotante de captura

Se activa desde **Editar → Configuración → Capturas**, en el bloque **Atajo de captura**, con **Mostrar botón flotante de captura**. Está activado por defecto y no necesita librerías nuevas.

- **Un clic:** inicia la selección de captura habitual.
- **Arrastrar:** cambia la posición sin tomar una captura.
- **Clic derecho:** Capturar pantalla, Abrir IMG Viewer u Ocultar botón.
- **Ocultar botón:** desactiva la preferencia. Puedes recuperarlo desde Configuración.

La posición se recuerda y se ajusta para seguir visible si cambias o desconectas monitores. El botón se oculta antes de congelar la pantalla y reaparece al terminar o cancelar.

Permanece disponible mientras IMG Viewer esté ejecutándose, incluido el modo bandeja; salir de la aplicación también lo cierra. Si quieres que esté disponible al iniciar Windows, activa por separado **General → Iniciar con Windows**.

La posición y activación se guardan para el usuario actual de Windows. Las pruebas de interacción se realizaron con una captura simulada, sin guardar imágenes del escritorio del usuario.
